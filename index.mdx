Payment Gateway is a payment aggregator API that intelligently routes transactions across multiple payment processors—Razorpay, Cashfree, PayU, Juspay, and more—using a multi-factor scoring engine. It handles retries, circuit breaking, idempotency, and gateway failover automatically so your customers experience the highest possible payment success rates.

## How It Works

Payment Gateway sits between your application and the payment networks. When you submit a payment, the gateway scores every available processor in real time—weighing recent success rates, latency, payment method affinity, bank affinity, and amount tiers—then attempts them in ranked order. If a gateway fails with a retryable error, the next candidate is tried automatically within your configured latency budget.

<Steps>
  <Step title="Submit a payment">
    Send a `POST /payments` request with your merchant ID, customer ID, amount, payment method, and instrument details. Include an `idempotency-key` header to prevent duplicate charges.
  </Step>
  <Step title="Gateway routes automatically">
    The scoring engine ranks all eligible gateways and attempts them in order. Circuit breakers skip unhealthy gateways; retry policies control how many attempts are made.
  </Step>
  <Step title="Receive the result">
    The response tells you whether the payment succeeded, failed, or is pending verification. For timeout cases, an asynchronous verifier resolves the final state.
  </Step>
  <Step title="Monitor and optimize">
    Use the Metrics API to track real-time success rates and latency per gateway. Run A/B experiments or let the bandit optimizer continuously learn the best gateway ordering for each payment segment.
  </Step>
</Steps>
