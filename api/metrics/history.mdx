---
title: "GET /metrics/history/{gatewayName} — Historical Metrics"
sidebarTitle: "History"
description: "Query persisted historical metric snapshots for a gateway, enabling trend analysis and post-incident review beyond the rolling hot-metric windows."
---

The `/metrics/history/{gatewayName}` endpoint retrieves metric records that have been persisted to the database by the metrics service. Unlike the hot-metrics endpoints — which serve data from rolling windows — the history endpoint gives you access to longer-term metric snapshots retained for trend analysis, dashboards, and post-incident review. No authentication is required.

## Endpoint

```
GET http://localhost:3001/metrics/history/{gatewayName}
```

## Path Parameters

<ParamField path="gatewayName" type="string" required>
  The gateway identifier whose history you want to retrieve. Examples: `cashfree`, `razorpay`, `payu`, `juspay`. The endpoint returns up to 240 of the most recent records, ordered by `windowStart` descending.
</ParamField>

## Example Request

```bash
curl http://localhost:3001/metrics/history/cashfree
```

## Response Fields

The response is a JSON array of historical metric record objects. Each object represents one persisted metric snapshot for a specific gateway, payment method, and time window.

<ResponseField name="id" type="string (UUID)">
  Unique identifier for this metric record.
</ResponseField>

<ResponseField name="gatewayName" type="string">
  The name of the gateway this record belongs to (e.g., `"cashfree"`).
</ResponseField>

<ResponseField name="paymentMethod" type="string">
  The payment method this record covers (e.g., `"UPI"`, `"CARD"`, `"NETBANKING"`, `"WALLET"`).
</ResponseField>

<ResponseField name="bank" type="string | null">
  The bank associated with this record, if applicable. `null` when not set.
</ResponseField>

<ResponseField name="windowStart" type="string (datetime)">
  ISO 8601 timestamp indicating the start of the measurement window for this snapshot, floored to the nearest minute.
</ResponseField>

<ResponseField name="windowSizeSeconds" type="integer">
  The duration of the measurement window in seconds. Possible values: `60` (1 minute), `300` (5 minutes), `900` (15 minutes), `3600` (60 minutes).
</ResponseField>

<ResponseField name="successCount" type="integer">
  Number of payment attempts that returned a `SUCCESS` status during this window.
</ResponseField>

<ResponseField name="failureCount" type="integer">
  Number of payment attempts that returned a `FAILED` status during this window.
</ResponseField>

<ResponseField name="timeoutCount" type="integer">
  Number of payment attempts that returned a `TIMEOUT` status during this window.
</ResponseField>

<ResponseField name="totalCount" type="integer">
  Total number of payment attempts recorded during this window.
</ResponseField>

<ResponseField name="p50LatencyMs" type="number | null">
  50th-percentile (median) latency in milliseconds during the window. May be `null` if no attempts were recorded.
</ResponseField>

<ResponseField name="p95LatencyMs" type="number | null">
  95th-percentile latency in milliseconds during the window. May be `null` if no attempts were recorded.
</ResponseField>

<ResponseField name="successRate" type="number">
  The success rate for this gateway and method during the window, as a decimal between `0` and `1`.
</ResponseField>

<ResponseField name="createdAt" type="string (datetime)">
  ISO 8601 timestamp of when this record was created.
</ResponseField>

<ResponseField name="updatedAt" type="string (datetime)">
  ISO 8601 timestamp of when this record was last updated.
</ResponseField>

<Note>
  **Hot metrics vs. historical metrics serve different purposes.** Hot metrics (available via `/metrics/gateways`) reflect recent rolling windows of activity and are what the routing engine uses in real time. Historical metrics (this endpoint) are intended for trend analysis, dashboards, and post-incident review. The most recent history record may lag slightly behind the current hot metric values.
</Note>
