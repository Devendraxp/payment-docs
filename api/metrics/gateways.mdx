The `/metrics/gateways` endpoint returns real-time hot metrics for all gateways currently tracked by the metrics service. The response groups results by gateway name and then by payment method, giving you an instant snapshot of how every gateway is performing right now. No authentication is required to call this endpoint.

## Endpoint

```
GET http://localhost:3001/metrics/gateways
```

## Request

This endpoint accepts no query parameters or request body.

## Example Request

```bash
curl http://localhost:3001/metrics/gateways
```

## Response Fields

The top-level response contains a single `gateways` key whose value is an object keyed by gateway name. Each gateway value is itself an object keyed by payment method (e.g., `UPI`, `CARD`). Each method entry contains rolling-window statistics across four time windows (`1m`, `5m`, `15m`, `60m`), plus a timestamp.

<ResponseField name="gateways" type="object" required>
  A map of gateway names to their per-method metric objects.

  <Expandable title="gateways[gatewayName]">
    <ResponseField name="[method]" type="object">
      Metrics object for a specific payment method within this gateway. Each field name is suffixed with the window duration: `_1m`, `_5m`, `_15m`, or `_60m`.

      <Expandable title="method metrics">
        <ResponseField name="success_rate_{window}" type="number">
          Rolling success rate over the window, as a decimal between `0` and `1` (e.g., `0.9732` means 97.32%). Computed as `successCount / totalCount`; returns `0` when there are no attempts.
        </ResponseField>

        <ResponseField name="success_{window}" type="integer">
          Number of payment attempts that returned a `SUCCESS` status within the window.
        </ResponseField>

        <ResponseField name="fail_{window}" type="integer">
          Number of payment attempts that returned a `FAILED` status within the window.
        </ResponseField>

        <ResponseField name="timeout_{window}" type="integer">
          Number of payment attempts that returned a `TIMEOUT` status within the window.
        </ResponseField>

        <ResponseField name="total_{window}" type="integer">
          Total number of payment attempts recorded within the window, including successes, failures, and timeouts.
        </ResponseField>

        <ResponseField name="p50_{window}" type="number">
          50th-percentile (median) latency in milliseconds over the window.
        </ResponseField>

        <ResponseField name="p95_{window}" type="number">
          95th-percentile latency in milliseconds over the window. Useful for assessing tail latency; lower values indicate a more responsive gateway.
        </ResponseField>

        <ResponseField name="p99_{window}" type="number">
          99th-percentile latency in milliseconds over the window.
        </ResponseField>

        <ResponseField name="last_updated" type="string">
          ISO 8601 timestamp of the last time this metric entry was updated.
        </ResponseField>
      </Expandable>
    </ResponseField>
  </Expandable>
</ResponseField>

<Note>
  Hot metrics are **eventually consistent**. There may be a brief delay of a few seconds between when a payment is processed and when its outcome is reflected in these metrics. Do not rely on this endpoint for strict real-time consistency guarantees.
</Note>
