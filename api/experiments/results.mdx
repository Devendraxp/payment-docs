---
title: "GET /experiments/{id}/results — Experiment Results"
sidebarTitle: "GET /results"
description: "Retrieve aggregated success rate metrics for both control and treatment variants of an experiment, including improvement percentage and significance status."
---

The `/experiments/{experimentId}/results` endpoint gives you a side-by-side summary of how the control and treatment variants have performed over the lifetime of an experiment. The response includes attempt counts and success rates for each variant, the percentage improvement (or regression) of the treatment over the control, and a flag indicating whether enough data has accumulated to consider the results statistically conclusive. No authentication is required.

## Endpoint

```
GET http://localhost:3002/experiments/{experimentId}/results
```

## Path Parameters

<ParamField path="experimentId" type="string (UUID)" required>
  The UUID of the experiment whose results you want to retrieve. You can find this ID in the response from `POST /experiments` or `GET /experiments`. Passing an invalid UUID returns a `400` validation error.
</ParamField>

## Example Request

```bash
curl http://localhost:3002/experiments/e1a2b3c4-d5e6-7f89-ab01-cd23ef456789/results
```

## Response Fields

<ResponseField name="experimentId" type="string (UUID)">
  The experiment's unique identifier, echoed back for easy correlation.
</ResponseField>

<ResponseField name="name" type="string">
  The human-readable name of the experiment.
</ResponseField>

<ResponseField name="status" type="string">
  The current lifecycle status of the experiment: `DRAFT`, `ACTIVE`, `PAUSED`, or `COMPLETED`.
</ResponseField>

<ResponseField name="control" type="object">
  Aggregated outcome metrics for customers assigned to the **control** variant.

  <Expandable title="control fields">
    <ResponseField name="successRate" type="number">
      The success rate for the control variant, as a decimal between `0` and `1`.
    </ResponseField>

    <ResponseField name="totalAttempts" type="integer">
      Total number of payment attempts recorded in the control group.
    </ResponseField>

    <ResponseField name="successCount" type="integer">
      Number of successful payment attempts in the control group.
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="treatment" type="object">
  Aggregated outcome metrics for customers assigned to the **treatment** variant.

  <Expandable title="treatment fields">
    <ResponseField name="successRate" type="number">
      The success rate for the treatment variant, as a decimal between `0` and `1`.
    </ResponseField>

    <ResponseField name="totalAttempts" type="integer">
      Total number of payment attempts recorded in the treatment group.
    </ResponseField>

    <ResponseField name="successCount" type="integer">
      Number of successful payment attempts in the treatment group.
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="improvement" type="number">
  The percentage improvement of the treatment variant over the control. A positive value means the treatment is performing better. Calculated as `((treatment.successRate - control.successRate) / control.successRate) * 100`. A negative value indicates a regression.
</ResponseField>

<ResponseField name="conclusionReached" type="boolean">
  Indicates whether the experiment has collected enough data to draw a statistically meaningful conclusion. When `false`, continue running the experiment to accumulate more samples before acting on the results.
</ResponseField>

## Example Response

```json
{
  "experimentId": "e1a2b3c4-d5e6-7f89-ab01-cd23ef456789",
  "name": "Cashfree first for UPI",
  "status": "ACTIVE",
  "control": {
    "successRate": 0.9420,
    "totalAttempts": 1842,
    "successCount": 1735
  },
  "treatment": {
    "successRate": 0.9671,
    "totalAttempts": 1889,
    "successCount": 1826
  },
  "improvement": 2.67,
  "conclusionReached": true
}
```

<Tip>
  Wait until you have **at least a few hundred attempts per variant** before drawing conclusions from the results. With too few samples, random variance can make a neutral or even harmful treatment appear beneficial. As a rule of thumb, aim for 500+ attempts in each group before using `conclusionReached` as your primary signal to stop the experiment.
</Tip>
