---
title: "GET /experiments/{id}/results — Experiment Results"
sidebarTitle: "GET /results"
description: "Retrieve aggregated success rate and latency metrics for both the control and treatment variants of a completed or active experiment."
---

The `/experiments/{experimentId}/results` endpoint gives you a side-by-side summary of how the control and treatment variants have performed over the lifetime of an experiment. The response includes the full experiment object alongside per-variant metrics: sample count, success count, success rate, and average payment latency. No authentication is required.

## Endpoint

```
GET http://localhost:3002/experiments/{experimentId}/results
```

## Path Parameters

<ParamField path="experimentId" type="string (UUID)" required>
  The UUID of the experiment whose results you want to retrieve. You can find this ID in the response from `POST /experiments` or `GET /experiments`. Passing an invalid UUID returns a `400` validation error.
</ParamField>

## Example Request

```bash
curl http://localhost:3002/experiments/e1a2b3c4-d5e6-7f89-ab01-cd23ef456789/results
```

## Response Fields

<ResponseField name="experiment" type="object">
  The full experiment record, identical to what `GET /experiments/{id}` returns — includes `id`, `name`, `status`, `controlWeight`, `treatmentWeight`, `treatmentConfig`, `targetMethods`, `guardrailConfig`, `startsAt`, `endsAt`, `createdAt`, and `updatedAt`.
</ResponseField>

<ResponseField name="results" type="object">
  An object with two keys — `CONTROL` and `TREATMENT` — each containing aggregated outcome metrics for that variant.

  <Expandable title="CONTROL and TREATMENT fields">
    <ResponseField name="samples" type="integer">
      Total number of payment outcomes recorded for this variant.
    </ResponseField>

    <ResponseField name="successCount" type="integer">
      Number of payment outcomes with a final status of `SUCCESS`.
    </ResponseField>

    <ResponseField name="successRate" type="number">
      The success rate for this variant, as a decimal between `0` and `1`, rounded to four decimal places. Returns `0` when `samples` is `0`.
    </ResponseField>

    <ResponseField name="averageLatencyMs" type="integer">
      The average end-to-end payment latency in milliseconds across all outcomes in this variant. Returns `0` when `samples` is `0`.
    </ResponseField>
  </Expandable>
</ResponseField>

## Example Response

```json
{
  "experiment": {
    "id": "e1a2b3c4-d5e6-7f89-ab01-cd23ef456789",
    "name": "Cashfree first for UPI",
    "status": "ACTIVE",
    "controlWeight": 0.5,
    "treatmentWeight": 0.5,
    "treatmentConfig": {
      "gatewayOrderOverride": ["cashfree", "razorpay", "payu", "juspay"]
    },
    "targetMethods": ["UPI"],
    "guardrailConfig": null,
    "startsAt": "2024-11-15T12:00:00.000Z",
    "endsAt": "2024-11-22T12:00:00.000Z",
    "createdAt": "2024-11-15T10:30:00.000Z",
    "updatedAt": "2024-11-15T12:00:00.000Z"
  },
  "results": {
    "CONTROL": {
      "samples": 1842,
      "successCount": 1735,
      "successRate": 0.9420,
      "averageLatencyMs": 312
    },
    "TREATMENT": {
      "samples": 1889,
      "successCount": 1826,
      "successRate": 0.9671,
      "averageLatencyMs": 287
    }
  }
}
```

<Tip>
  To compute the percentage improvement of the treatment over control, use `((treatment.successRate - control.successRate) / control.successRate) * 100`. In the example above that works out to approximately `+2.67%`. Wait until you have **at least a few hundred samples per variant** before drawing conclusions — with too few data points, random variance can make a neutral or even harmful treatment appear beneficial.
</Tip>

## Errors

| Status | Reason |
|---|---|
| `400 Bad Request` | The `experimentId` path parameter is not a valid UUID. |
| `404 Not Found` | No experiment exists with the given ID. |
