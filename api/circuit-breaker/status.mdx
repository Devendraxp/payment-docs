title: "GET /circuit-breaker/status — View All Circuit States"

The `GET /circuit-breaker/status` endpoint returns a snapshot of every circuit breaker the orchestrator is currently tracking. Each circuit corresponds to a unique gateway-method pair (e.g., `razorpay:UPI`) and reflects real-time failure and success data from the recent rolling window. You can use this endpoint to confirm whether a gateway has tripped, to monitor recovery progress in `HALF_OPEN` state, or to verify that a forced state change took effect. No authentication is required.

## Endpoint

```
GET http://localhost:3000/circuit-breaker/status
```

## Example Request

```bash
curl http://localhost:3000/circuit-breaker/status
```

## Circuit States

Each circuit breaker operates as a three-state machine:

| State | Meaning |
|-------|---------|
| `CLOSED` | The circuit is healthy. All traffic flows through normally. |
| `OPEN` | The circuit is unhealthy. The orchestrator skips this gateway-method pair and routes to alternatives. |
| `HALF_OPEN` | The circuit is probing for recovery. A limited number of requests are allowed through; if they succeed the circuit closes, otherwise it reopens. |

## Response

The response object is keyed by `circuit_breaker:{gatewayName}:{method}` strings. Each value is a circuit state object with the following fields.

<ResponseField name="state" type="string" required>
  Current circuit state: `CLOSED`, `OPEN`, or `HALF_OPEN`.
</ResponseField>

<ResponseField name="failureCount" type="integer" required>
  Number of failures recorded in the current tracking window. When this count exceeds the configured threshold the circuit trips to `OPEN`.
</ResponseField>

<ResponseField name="lastFailureTs" type="number" required>
  Unix timestamp (milliseconds) of the most recent failure recorded for this circuit. Use this to determine how long ago the last failure occurred.
</ResponseField>

<ResponseField name="probeCount" type="integer" required>
  Number of probe requests sent while the circuit is in `HALF_OPEN` state. Resets to `0` when the circuit transitions out of `HALF_OPEN`.
</ResponseField>

<ResponseField name="recentSuccesses" type="integer" required>
  Number of successful requests recorded in the current rolling window.
</ResponseField>

<ResponseField name="recentAttempts" type="integer" required>
  Total number of requests (successes + failures) recorded in the current rolling window.
</ResponseField>
