---
title: "GET /payments/{paymentId} — Retrieve a Payment"
sidebarTitle: "GET /payments/:id"
description: "Retrieve a payment by its UUID to inspect its current status, instrument details, final gateway, and timestamps."
---

The `GET /payments/{paymentId}` endpoint returns the full stored record for a single payment. Use it to check the current status of a payment after creation, inspect the instrument that was submitted, or confirm when the payment was last updated. No authentication is required to call this endpoint.

---

## Endpoint

```
GET http://localhost:3000/payments/{paymentId}
```

---

## Path Parameters

<ParamField path="paymentId" type="string" required>
  The UUID of the payment to retrieve. This is the `paymentId` value returned when you created the payment.
</ParamField>

---

## Example Request

```bash
curl http://localhost:3000/payments/b3e2a1d4-7f6e-4c5b-9a8d-123456789abc
```

---

## Response Fields

<ResponseField name="id" type="string">
  The UUID uniquely identifying this payment.
</ResponseField>

<ResponseField name="merchantId" type="string">
  The merchant identifier supplied when the payment was created.
</ResponseField>

<ResponseField name="customerId" type="string">
  The customer identifier supplied when the payment was created.
</ResponseField>

<ResponseField name="amountMinor" type="integer">
  The payment amount in the smallest currency unit (for example, paise for INR).
</ResponseField>

<ResponseField name="paymentMethod" type="string">
  The payment method used. One of `UPI`, `CARD`, `NETBANKING`, or `WALLET`.
</ResponseField>

<ResponseField name="instrument" type="object">
  The original instrument details submitted with the payment request. Structure varies by `paymentMethod`.
</ResponseField>

<ResponseField name="status" type="string">
  The current status of the payment. One of:
  - `PENDING` — the payment is still being processed.
  - `SUCCESS` — the payment was confirmed by the gateway.
  - `FAILED` — all gateway attempts were exhausted without success.
  - `PENDING_VERIFICATION` — the payment timed out at the gateway and is being resolved asynchronously.
</ResponseField>

<ResponseField name="finalGateway" type="string | null">
  The name of the gateway that successfully processed the payment. `null` if the payment has not yet succeeded.
</ResponseField>

<ResponseField name="verifiedAt" type="datetime | null">
  The timestamp at which an async verification job resolved a `PENDING_VERIFICATION` payment. `null` if the payment was never in that state, or if verification has not yet completed.
</ResponseField>

<ResponseField name="createdAt" type="datetime">
  ISO 8601 timestamp of when the payment record was created.
</ResponseField>

<ResponseField name="updatedAt" type="datetime">
  ISO 8601 timestamp of the most recent update to the payment record.
</ResponseField>

---

## Error Responses

| HTTP Status | Cause                                                                          |
| ----------- | ------------------------------------------------------------------------------ |
| `400`       | The `paymentId` path parameter is not a valid UUID format.                     |
| `404`       | No payment exists with the given `paymentId`.                                  |
